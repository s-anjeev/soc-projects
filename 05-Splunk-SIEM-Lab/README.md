# Splunk SIEM Lab

This section demonstrates the use of Splunk SIEM for log ingestion, log analysis, event correlation, threat detection, threat hunting, and security monitoring.   

The projects in this section highlight practical Splunk capabilities, including data ingestion and normalization, searching and analyzing security logs, developing detection logic, correlating events, investigating security incidents, and performing threat hunting. They also demonstrate how Splunk can be used to identify suspicious activities and support security operations in a SOC environment.
