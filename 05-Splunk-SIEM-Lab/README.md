# Splunk SIEM Lab

This section demonstrates the use of Splunk SIEM for log ingestion, log analysis, event correlation, threat detection, threat hunting, and security monitoring.   

The projects in this section highlight practical Splunk capabilities, including data ingestion and normalization, searching and analyzing security logs, developing detection logic, correlating events, investigating security incidents, and performing threat hunting. They also demonstrate how Splunk can be used to identify suspicious activities and support security operations in a SOC environment.   

# Cases
## Case 01 — Log Ingestion Security Monitoring
Centralized Windows Server, Sysmon, Apache, and PowerShell logs into Splunk for centralized security monitoring.
- [View case 1](https://github.com/s-anjeev/soc-projects/tree/main/05-Splunk-SIEM-Lab/case-01-log-ingestion-security-monitoring)


## Case 02 — Brute Force Attack Detection
This lab demonstrates practical, hands-on experience in detecting multiple failed login attempts and identifying suspicious authentication behavior indicative of a credential brute-force attack.   
- [View Case 2](https://github.com/s-anjeev/soc-projects/tree/main/05-Splunk-SIEM-Lab/case-02-Brute-Force-Attack-Detection)
