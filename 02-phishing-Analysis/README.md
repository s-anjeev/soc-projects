# Phishing Analysis

## Overview
Phishing emails are one of the most common ways attackers try to break into organizations. Over 90% of successful cyberattacks begin with a phishing email. This section demonstrates the process of investigating suspicious emails reported by employees to identify whether they are malicious and extract all relevant indicators of compromise.

A phishing investigation in a real SOC typically involves:

- Reading the email carefully for obvious red flags
- Analysing email headers to trace the sending infrastructure
- Checking sending IPs on AbuseIPDB for reputation
- Checking links, Domains, IP on VirusTotal without clicking them
- Extracting all IOCs for blocking and further investigation
- Performing basic Malware Analysis on suspecious attachments 
- Advising on remediation steps
- User awarenes and training 


## Tools Used
- phishtool
- AbuseIPDB
- VirusTotal
- Manual email header analysis
